# Future-Engineers-2026
Repostitorio con la informacion del proyecto de exhibición para WRO Honduras 2026 en la categoría Future-Engineers
- Este proyecto ha sido posible gracias a la ayuda de STEM Center Honduras.
- Durante 1 mes hemos trabajado en el desarrollo de nuestros robots. Uno de ellos usa mindstorm ev3 para el desafío abierto, y el otro usa Arduino y un sensor Husky Lense de vision artificial para el desafío cerrado.
- Agradecemos la colaboración de STEM Center y la de todos los integrantes de el equipo por poder hacer este proyecto posible.
